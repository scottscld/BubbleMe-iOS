# Bubble Me for iPhone

This is a **finished Xcode project**. You do not create a new project in Xcode. You download this folder, open it, and press Play.

## Download (do this on your Mac)

**Fastest:** click this link on your Mac:

https://github.com/scottscld/BubbleMe-iOS/archive/refs/heads/main.zip

That saves `BubbleMe-iOS-main.zip`. Then:

1. Double-click the zip to unzip it.
2. Open the folder **BubbleMe-iOS-main**.
3. Double-click **BubbleMe.xcodeproj** (blue Xcode icon).
4. At the top of Xcode, pick any **iPhone** simulator.
5. Press the Play triangle (or Command + R).

The first run takes 1–3 minutes. A fake iPhone window opens.

### Or from the GitHub page

1. Open https://github.com/scottscld/BubbleMe-iOS
2. Click the green **Code** button
3. Click **Download ZIP**

## If Xcode asks about a Team

1. Left sidebar: click the blue **BubbleMe** at the very top
2. **Signing & Capabilities**
3. Check **Automatically manage signing**
4. Team → **Add Account…** → sign in with your Apple ID (free)

The Simulator works even with Team set to None. A real iPhone needs the Apple ID step.

## In the app

- Tap the photo circle to pick a shooter picture
- Tap **Play**, drag to aim, release to shoot
- **Bomb / Fire / Face** are at the bottom
- **Friends** has Messages, Email, and More (your 6-letter code)

You need a Mac with Xcode from the Mac App Store. Xcode does not run on Windows.

The Simulator cannot vibrate. Use a real iPhone for haptic rumble.
